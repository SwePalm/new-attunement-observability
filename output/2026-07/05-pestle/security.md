### Political
Core Shift Thesis:
Autonomous cyber-offense became a documented state instrument in 2026, making agent security a national-security matter while binding domestic security rules recede.
Forces:
1. The GTG-1002 disclosure (state-sponsored, 80–90% AI-executed against ~30 targets) establishes autonomous offense as an active geopolitical capability, not a projection.
2. EU omnibus deferral postponed high-risk security-control obligations, leaving the West's most comprehensive framework unenforced during the capability's emergence.
3. US executive suppression of state AI law removes potential subnational security mandates without federal replacement.
4. "AI sovereignty" discourse now includes offensive/defensive cyber capability as a strategic asset, pulling agent security into statecraft.

### Economic
Core Shift Thesis:
Security is being priced by insurers before it is mandated by regulators, making coverage conditions the effective security standard.
Forces:
1. ISO default AI exclusions plus affirmative products (Armilla, Testudo) make logging, oversight, and containment preconditions of insurability — insurance as security regulator.
2. Uninsurability criteria (autonomous, opaque, unlogged, single-provider systems) create a market price signal for insecure architecture ahead of any statute.
3. AI-augmented security operations correlate with lower breach costs, monetizing defensive automation and incentivizing its adoption where capital allows.
4. The controls gap (81% deploying agents vs 37–40% with containment) is an economic backlog: closing it is a capex line most under-resourced organizations cannot fund.

### Social
Core Shift Thesis:
Machine-speed offense stratifies vulnerability, converting security from a specialized concern into a general condition of digital participation unequally distributed.
Forces:
1. Autonomous enumeration lets attackers exploit thousands of soft targets at once, turning the well-defended/poorly-defended gap from degree into kind.
2. Under-resourced institutions (hospitals, schools, municipalities, mid-market firms) cannot staff AI-augmented defense, concentrating exposure.
3. Democratized offensive tooling (824 marketplace malicious skills) expands the attacker population as effort-per-attack collapses.
4. Workforce suspicion of its own tools emerges as coding/agent instruments are recognized as dual-use, straining the human-AI working relationship.

### Technological
Core Shift Thesis:
The control plane is shifting to agent gateways and agent-identity systems — security is being re-architected around non-human actors as first-class principals.
Forces:
1. Agent gateways (per-invocation policy checks, risk scoring, kill switches) implement in code the controls regulation has not mandated.
2. Identity systems extended to authenticate and authorize agents distinctly from human owners — access governance must now reason about non-human credentials.
3. Marketplace supply-chain risk (824 malicious skills of 10,700) imports package-ecosystem threats without inherited signing/review norms.
4. Symmetric capability (frontier models solving 93% of professional CTF tasks) means defense automates on the same curve as offense — the gating factor is adoption, not capability.

### Legal
Core Shift Thesis:
Security accountability is migrating into product-liability and insurance law because dedicated statutory security duties for AI agents do not yet bind.
Forces:
1. Product-liability doctrine (Character.AI, component-part reach) previews provider liability for insecure agent behavior, disciplining design ahead of security-specific statute.
2. Insurance contract terms function as enforceable security duties, with renewal as the compliance checkpoint.
3. Incident-evidence and audit-trail expectations (from insurers, procurement) create de facto breach-notification and forensic obligations without a statute.
4. Absence of agent-specific liability allocation leaves an open question of who answers when a hijacked agent (owner? provider? marketplace?) causes harm.

### Environmental
Core Shift Thesis:
Security's physical dependency is the concentrated compute and cloud substrate — the same concentration that creates efficiency creates systemic attack surface.
Forces:
1. ~80% cloud-based AI compute concentrates both capability and single-points-of-failure in a few hyperscale providers.
2. Autonomous agents running continuously consume resources and create persistent, always-on attack surface distinct from episodic human activity.
3. Infrastructure concentration means a successful attack on shared agent infrastructure could propagate across dependent organizations — coordination risk with a physical substrate.
