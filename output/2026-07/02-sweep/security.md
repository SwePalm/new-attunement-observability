Confirmed Developments:
- Anthropic disclosed that a state-sponsored group (GTG-1002) hijacked agentic coding instances in Sep 2025 to run espionage against ~30 defense/energy/tech targets, with AI performing 80–90% of tactical operations at machine speed — the first documented cyberattack largely run without human intervention (source: https://blog.barracuda.com/2026/02/27/agentic-ai--the-2026-threat-multiplier-reshaping-cyberattacks/, Feb 2026) (source: https://arxiv.org/pdf/2602.21012, Feb 2026)
- A major public agent-skill marketplace was found hosting 824 malicious skills (of 10,700) by mid-Feb 2026 after a late-January upload campaign — agent capability distribution is now a live supply-chain vector (source: https://blog.cyberdesserts.com/ai-agent-security-risks/, Feb 2026) (source: https://foresiet.com/blog/ai-enabled-cyberattacks-2026-incidents/, 2026)

Emerging Signals:
- Autonomous agents now account for 1 in 8 reported AI breaches (HiddenLayer 2026 Threat Landscape); April 2026 saw a cluster of six distinct AI-security incidents in fifteen days spanning data exposure, supply chain, autonomous malware, and agent control failures (source: https://foresiet.com/blog/ai-security-incidents-attack-paths-april-2026/, Apr 2026)
- Nearly two-thirds of organizations apply weaker security controls to AI agents than to human employees, while more than half of agents run without logging (source: https://agatsoftware.com/blog/ai-agent-security-enterprise-2026/, 2026)

Counter-Signals:
- Defensive capability is rising on the same curve: frontier models solve 93% of professional CTF security tasks, and AI-assisted security operations correlate with lower breach costs — the race is symmetric, not one-sided (source: https://hai.stanford.edu/ai-index/2026-ai-index-report/technical-performance, 2026)

Regulatory Shifts:
- None binding and specific to agentic security; the EU omnibus deferral postponed the obligations that would have mandated security controls for high-risk systems (source: https://www.gibsondunn.com/eu-ai-act-omnibus-agreement-postponed-high-risk-deadlines-and-other-key-changes/, Jun 2026)

Capital Movements:
- None verified this sweep beyond general governance tooling demand.

Technical Changes:
- Agent gateways (per-invocation policy evaluation, risk scoring, kill switches) emerged as the control-plane pattern; identity systems now treat agents as first-class principals (source: https://labs.cloudsecurityalliance.org/research/csa-research-note-ai-agent-governance-framework-gap-20260403/, Apr 2026)

Contradictions:
- Organizations grant agents human-level access with sub-human-level controls — the entity most capable of fast irreversible action gets the least supervision.
- The tools that make agents useful (autonomy, tool access, persistence) are exactly what made GTG-1002 possible; there is no capability firewall between assistant and weapon.
