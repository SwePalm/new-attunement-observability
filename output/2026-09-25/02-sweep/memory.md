# Evidence sweep, memory, 2026-09-25

Delta Since Last Sweep:
- The interval is 43 days, and Phase A of this run moved 0 of 9 live memory claims. The world did move, just not along any observable the ledger watches. Four first-party memory launches or announcements landed in the window: Claude memory extended to Cowork with a sensitive-topics exclusion on 25 Aug 2026 (source: https://support.claude.com/en/articles/12138966-release-notes, Sep 2026), Meta's Muse agent with persistent memory on 8 Sep 2026 (source: https://about.fb.com/news/2026/09/introducing-muse-personal-ai-agent/, Sep 2026), Claude Code Projects with shared project memory on 17 Sep 2026 (source: https://venturebeat.com/orchestration/anthropic-launches-claude-code-projects-an-always-on-conversation-that-remembers-and-delegates-your-long-running-dev-work, Sep 2026), and Google's server-side memory for Private AI Compute on 23 Sep 2026 (source: https://deepmind.google/blog/advancing-private-ai-compute-with-secure-server-side-memory/, Sep 2026).
- A new axis opened: provider-blind memory. Google and Meta each announced memory encrypted with keys only the user holds, and neither gave a ship date. The 2026-08-13 sweep had no item on memory confidentiality against the provider itself (source: https://www.helpnetsecurity.com/2026/09/24/google-private-ai-compute-server-side-memory/, Sep 2026).
- Memory integrity attacks moved from single vendors and academic papers to a coordinated disclosure across major vendor harnesses. On 24 Sep 2026 Darktrace published conversation history poisoning results against Claude Code, OpenAI Codex, AWS Kiro-CLI and Pi, after disclosing to the vendors on 18 Aug 2026 (source: https://www.darktrace.com/blog/hijacking-agentic-harnesses-to-attack-an-organization, Sep 2026).
- The first judicial signal in the window came from a German-language source rather than a DPA. On 17 Sep 2026 the Cologne Regional Court held that a chatbot processing sensitive data that users volunteer needs explicit Art. 9 GDPR consent (source: https://www.ra-plutte.de/lg-koeln-sensible-daten-in-ki-chatbots/, Sep 2026). No EU DPA, EDPB or state AG action naming assistant memory was found in the window, which matches this run's grading of memory-2026-07-01.

Confirmed Developments:
- Anthropic extended Claude memory to Cowork cloud sessions on 25 Aug 2026. Everything Claude remembers is now listed under Topics in Settings > Memory, where each item can be edited or deleted. Topics such as health or beliefs stay out of memory unless the user turns on "Include sensitive topics in memory". Memory is on by default for Free, Pro and Max and off by default for Team and Enterprise, and it now updates during conversations instead of after them (source: https://support.claude.com/en/articles/12138966-release-notes, Sep 2026) (source: https://www.androidheadlines.com/2026/08/anthropic-claude-cowork-memory-merge.html, Aug 2026)
- OpenAI is rolling out a Privacy Center in ChatGPT (reported from 21 to 23 Sep 2026) that explains Memory, personalised ads, temporary chats, connected apps and data use, and links to the existing controls. It changes no settings, and it states that deleting a conversation does not remove information saved in Memory from that conversation. The rollout covers Free, Go, Plus, Pro and Business, while ChatGPT Enterprise, Edu and ChatGPT for Healthcare are excluded for now (source: https://www.gsmdome.com/chatgpt-privacy-center-rolls-out-as-a-guide-to-existing-controls, Sep 2026) (source: https://www.indiatvnews.com/technology/news/chatgpt-privacy-center-rolling-out-soon-manage-memory-chats-apps-and-data-settings-2026-09-23-1055036, Sep 2026)
- Meta launched Muse, a personal AI agent, on 8 Sep 2026, for US users only, on web, iOS, Android and WhatsApp. Muse remembers "what matters to a person" to make unprompted suggestions, users can tell it to forget specific things, and it shows an audit trail of its actions. Meta says Muse data is not shared with its ad systems and promises a Muse Confidential VM "later this year", encrypted with a key only the user holds (source: https://about.fb.com/news/2026/09/introducing-muse-personal-ai-agent/, Sep 2026) (source: https://techcrunch.com/2026/09/08/meta-debuts-its-muse-ai-agent-will-consumers-trust-it/, Sep 2026)
- Google DeepMind announced persistent server-side memory for Private AI Compute on 23 Sep 2026. Data sits in per-user encrypted storage inside hardware-enforced secure enclaves, and the keys are held only on the user's devices. Google also published an updated whitepaper, an independent audit and a tamper-proof record of its server software. No launch date and no shipping product were named (source: https://deepmind.google/blog/advancing-private-ai-compute-with-secure-server-side-memory/, Sep 2026) (source: https://www.helpnetsecurity.com/2026/09/24/google-private-ai-compute-server-side-memory/, Sep 2026)
- Darktrace published "conversation history poisoning" research on 24 Sep 2026, after disclosing to Anthropic, OpenAI and AWS on 18 Aug 2026. Agent harnesses store conversation history client-side, often in local SQLite, with no check that stored responses really came from the model. Claude Code, OpenAI Codex, AWS Kiro-CLI and the open-source Pi all accepted fabricated history, which was planted through a single malicious package such as an MCP server. The recommended fix is provider-side cryptographic signing of returned messages, which end users cannot deploy themselves (source: https://www.darktrace.com/blog/hijacking-agentic-harnesses-to-attack-an-organization, Sep 2026) (source: https://tech.yahoo.com/cybersecurity/articles/darktrace-proved-ai-agent-tools-235742644.html, Sep 2026)
- Anthropic began a beta of redesigned Claude Code Projects on 17 Sep 2026 for selected Pro and Max cloud-session users. A coordinator splits work into parallel threads, and every thread writes to and reads from a shared Project memory that keeps decisions such as a moved release date or a dropped feature. Team and Enterprise are due to follow (source: https://venturebeat.com/orchestration/anthropic-launches-claude-code-projects-an-always-on-conversation-that-remembers-and-delegates-your-long-running-dev-work, Sep 2026) (source: https://www.unite.ai/anthropic-redesigns-claude-code-projects-to-coordinate-agent-threads/, Sep 2026)

Emerging Signals:
- Two platform vendors are converging on provider-blind memory, meaning memory encrypted under user-held keys so the provider cannot read it: Google through Private AI Compute memory (23 Sep 2026) and Meta through the promised Muse Confidential VM. If shipped, this would change what a subpoena or a breach of the provider can reach (source: https://deepmind.google/blog/advancing-private-ai-compute-with-secure-server-side-memory/, Sep 2026)
- Enterprise trade press now treats derived AI memory as its own data-governance layer. TechTarget names Writer Enterprise Brain, Amazon Bedrock AgentCore Memory, Couchbase Agent Memory and Gemini Enterprise Memory Bank, and warns that "the derived memory can be easier to miss" than the governed source data (source: https://www.techtarget.com/it-strategy/news/366650847/Persistent-AI-memory-adds-another-layer-to-enterprise-data, Sep 2026)
- Consumer vendors are starting to gate memory by data category rather than all-or-nothing. Anthropic excludes health and belief topics by default, and reporting on the same launch says high-risk data such as government IDs, financial accounts and immigration records is barred from storage (source: https://www.androidheadlines.com/2026/08/anthropic-claude-cowork-memory-merge.html, Aug 2026)

Counter-Signals:
- Deletion non-propagation is becoming a standing, explained design choice rather than a gap awaiting a fix. OpenAI's new Privacy Center tells users that deleting a chat does not remove memory saved from it, which adds to Claude's help-centre statement recorded in this run's grading of memory-2026-08-02 (source: https://www.gsmdome.com/chatgpt-privacy-center-rolls-out-as-a-guide-to-existing-controls, Sep 2026)
- The provider-blind memory story is still announcement-only. Google gave no launch date, and Help Net Security describes the use cases as architectural potential rather than available features. Meta's Confidential VM is dated only "later this year" (source: https://www.helpnetsecurity.com/2026/09/24/google-private-ai-compute-server-side-memory/, Sep 2026)

Regulatory Shifts:
- In a judgment of 17 Sep 2026 (33 O 120/24, vzbv v. Snap Group Limited), the Cologne Regional Court held that Snapchat's My AI chatbot processed sensitive personal data without the explicit consent Art. 9(2) GDPR requires, even though users volunteered the data unprompted, because the chatbot encourages such disclosure. Chat inputs were used for ad personalisation. The court granted an injunction and held that pre-ticked checkboxes are not consent. The case concerns chat inputs rather than a persistent memory feature, and the sources do not say whether the judgment is final (source: https://www.ra-plutte.de/lg-koeln-sensible-daten-in-ki-chatbots/, Sep 2026) (source: https://shopbetreiber-blog.de/lg-koeln-ki-chatbots-duerfen-sensible-daten-nur-mit-einwilligung-verarbeiten, Sep 2026)

Capital Movements:
- Metacognition, an Adelaide-based lab founded by Anton van den Hengel, Stephen Gould and Paul Dalby, raised a $10 million pre-seed round from Main Sequence (reported 9 to 10 Sep 2026) to build a persistent-memory and reasoning layer beneath frontier models (source: https://www.forbes.com.au/news/entrepreneurs/australian-ai-lab-metacognition-caps-record-pre-seed-raise/, Sep 2026) (source: https://techstartups.com/2026/09/10/startup-funding-news-today-september-10-2026-metacognition-ai-dyu-sinapisai-wyre-ai-more/, Sep 2026)

Technical Changes:
- Claude consumer memory moved from post-session processing to updating during conversations, and one memory store now spans chat and Cowork cloud sessions. This builds on the 10 Jul 2026 switch from a daily summary to individual categorised entries (source: https://support.claude.com/en/articles/12138966-release-notes, Sep 2026)
- Google's Private AI Compute memory design uses per-user databases, device-held keys, an authenticated end-to-end encrypted channel into secure enclaves, and decryption only for the duration of a task. It is backed by an independent audit and a tamper-proof public record of the server software (source: https://deepmind.google/blog/advancing-private-ai-compute-with-secure-server-side-memory/, Sep 2026)
- Multi-agent shared memory has reached a first-party developer product: in Claude Code Projects, parallel worker threads contribute to and draw from one shared Project memory plus a persistent library of files and artifacts (source: https://www.unite.ai/anthropic-redesigns-claude-code-projects-to-coordinate-agent-threads/, Sep 2026)

Contradictions:
- Vendors are engineering memory confidentiality against themselves (Google's device-held keys, Meta's Confidential VM) while local agent memory has no integrity protection at all. Darktrace found that four harnesses trust unauthenticated local conversation history as ground truth. Confidentiality against the provider is advancing faster than integrity against a local attacker.
- Anthropic excludes health and belief topics from memory by default, in effect a category rule close to Art. 9 GDPR, three weeks before the Cologne court required explicit consent for chatbots handling volunteered sensitive data. The vendor control came first and the court second, which matches CAL-003's reading that non-state mechanisms lead.
- Memory keeps spreading to new surfaces (Cowork, Claude Code Projects, Muse, Private AI Compute), while the governance surfaces the ledger watches (compliance retrieval, deletion propagation, structured export, MCP) did not move in 43 days. Adoption and governance are diverging, and the ledger's observables sit entirely on the governance side.
- Unverified item not used: TechRepublic and Crypto Briefing coverage of Google's memory and of a "Meta Proactive Memory Agent" could not be opened (Cloudflare and JavaScript walls), so only the DeepMind primary post and Help Net Security are relied on. No negative is inferred from the unreachable pages.
