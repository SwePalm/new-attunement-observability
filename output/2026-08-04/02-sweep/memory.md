# Evidence sweep, memory, 2026-08-04

Delta Since Last Sweep:
- The 2026-07-03 sweep wrote "None" under Regulatory Shifts and "None verified" under Capital Movements. Both were wrong by omission: Spain's AEPD had already published agentic AI guidance naming memory poisoning and unauthorised access to agentic memory as data protection threats (Feb 2026), and Engram raised 98M USD for an enterprise memory layer (Jun 2026).
- The control surface the ledger assumed has changed. Last sweep described user-inspectable memory stores; since 4 Jun 2026 OpenAI's "dreaming" replaces the user-curated saved-memories list with background synthesis, and on 10 Jul 2026 Anthropic replaced Claude's daily memory summary with individually categorised entries. Memory is now written by the system, not curated by the user.
- Memory write-integrity became an operational attack surface in a single week: the MemGhost paper (6 Jul 2026) and CVE-2026-59705 in mem0's OpenMemory (7 Jul 2026, CVSS 4.0 9.3 critical). Open claim memory-2026-07-03 anticipated disclosure harm (leak or subpoena) and does not cover adversarial writes.
- A counter-direction the ledger did not anticipate: US courts began shielding AI prompts and outputs from discovery in Jun 2026 (Texas and New York), which cuts against the subpoena route assumed by memory-2026-07-03.

Confirmed Developments:
- OpenAI shipped "dreaming" on 4 Jun 2026, a background synthesis system that curates and rewrites ChatGPT memories automatically from years of chat history without user prompting (example given: "You're going to Singapore in July" becomes "You went to Singapore in July 2026"), rolling out to Plus and Pro users in the US first; the accompanying memory summary page is explicitly not a complete record of what the model may remember, and deleting a conversation does not remove memories derived from it (source: https://openai.com/index/chatgpt-memory-dreaming/, Jun 2026) (source: https://www.techtimes.com/articles/317840/20260605/chatgpt-memory-dreaming-update-openai-rewrites-personalization-engine-limits-audit-trail.htm, Jun 2026)
- Anthropic restructured consumer Claude memory on 10 Jul 2026 into individual categorised entries that Claude reads and updates during conversations, replacing the previous daily memory summary, and on 9 Jul 2026 launched Reflect (Settings > Reflect), a beta monthly recap of conversation topics and activity patterns that requires memory to be enabled, on Free, Pro and Max (source: https://support.claude.com/en/articles/12138966-release-notes, Jul 2026) (source: https://releasebot.io/updates/anthropic/claude, Jul 2026)
- MemGhost demonstrated one-shot stealthy memory injection against persistent personal agents: a single email causes the agent to write a false fact to its persistent memory, conceal the write, and rely on it in later sessions, with 87.5% success against OpenClaw on GPT-5.4 and 71.4% against the Claude Code SDK on Sonnet 4.6, transferring across filesystem and vector (Mem0) memory backends and defeating input, model and system level defences (source: https://arxiv.org/abs/2607.05189, Jul 2026) (source: https://thehackernews.com/2026/07/new-memghost-attack-plants-persistent.html, Jul 2026)

Emerging Signals:
- Memory-write provenance is being discussed as a product control rather than a research proposal: in response to MemGhost, OpenClaw said it is weighing memory-write controls including provenance tracking and confirmation prompts before an agent commits to persistent memory (source: https://thehackernews.com/2026/07/new-memghost-attack-plants-persistent.html, Jul 2026)
- Memory is becoming a retrospective product surface, not only a personalisation input: Anthropic's Reflect turns accumulated memory into a monthly narrative of what the user has been doing, shipped as beta across Free, Pro and Max on 9 Jul 2026 (source: https://releasebot.io/updates/anthropic/claude, Jul 2026)
- Memory is now a first-class platform API with lifecycle events: Anthropic's developer platform added memory store lifecycle webhooks and a dedicated agent-memory-2026-07-22 beta header governing memory listing semantics, superseding the earlier managed-agents header on memory store endpoints (source: https://platform.claude.com/docs/en/release-notes/overview, Aug 2026)

Counter-Signals:
- The evidentiary route the ledger assumed is narrowing, not widening. On 3 Jun 2026 the Texas Business Court (Tate Group Automotive v. Legacy Automotive Capital) held a party's own ChatGPT conversations to be protected work product, and on 4 Jun 2026 the Supreme Court of New York, Nassau County (Assini v. Hayward) quashed non-party subpoenas seeking a litigant's AI prompts, uploads and outputs (source: https://www.spencerfane.com/insight/courts-begin-shielding-ai-prompts-and-outputs-from-discovery-new-york-and-texas-recognize-work-product-protection-for-ai-assisted-litigation-work/, Jul 2026)
- Users are not the authors of their own memory profiles, which weakens consent-based framings of memory governance. An ACM Web Conference study of 2,050 ChatGPT memory entries from 80 users found 96% were created automatically by the system and only 4% at explicit user instruction, with 28% containing information the GDPR classifies as sensitive personal data (source: https://www.cjr.org/tow_center/chatbots-memory-remember-users-conversations-history-openai-sam-altman-llm-gemini.php, Apr 2026)

Regulatory Shifts:
- Spain's AEPD published agentic AI data protection guidance (v1.1, Feb 2026) that treats memory as a governed component: it names memory and RAG poisoning and unauthorised access to agentic memory among unauthorised-processing threats, requires compartmentalisation between processing contexts, requires memory to store "the minimum necessary for the agent's operation", and requires strict retention periods plus procedures for exercising data subject rights over memory (source: https://www.aepd.es/en/guides/agentic-artificial-intelligence.pdf, Feb 2026)
- EU AI Act Annex III high-risk rules and Article 50 transparency obligations entered application on 2 Aug 2026 with national and EU enforcement starting, while high-risk AI embedded in regulated products remains deferred to 2 Aug 2027 and the Commission has proposed linking that date to standards availability (source: https://ai-act-service-desk.ec.europa.eu/en/ai-act/timeline/timeline-implementation-eu-ai-act, Aug 2026)

Capital Movements:
- Engram emerged from stealth on 23 Jun 2026 with 98M USD from General Catalyst, Kleiner Perkins, Sequoia and Andrej Karpathy, eight months old and 13 employees, selling a "learned memory" layer that encodes company-specific workflows and claims parity with frontier models on some enterprise tasks using up to 100x fewer tokens, with Microsoft, Notion and Harvey named as customers (source: https://techstartups.com/2026/06/23/engram-raises-98-million-to-help-companies-lower-ai-token-costs-with-smarter-memory-models/, Jun 2026)

Technical Changes:
- CVE-2026-59705, published 7 Jul 2026, records that mem0's openmemory/api registered API routers without authentication middleware, letting unauthenticated attackers read, write and delete arbitrary user memories by supplying arbitrary user IDs, CWE-306, CVSS 4.0 9.3 and CVSS 3.1 9.8, affecting mem0ai prior to commit a3154d5 (source: https://nvd.nist.gov/vuln/detail/CVE-2026-59705, Jul 2026)
- The MCP specification released 2026-07-28 moved the protocol core from bidirectional stateful to stateless request/response, removed the initialize handshake and Mcp-Session-Id header, and contains no memory, persistence or provenance primitive; state is pushed to application-minted handles passed as tool arguments (source: https://blog.modelcontextprotocol.io/posts/2026-07-28/, Jul 2026)
- The taxonomy predates the exploits: OWASP's Top 10 for Agentic Applications, released 9 Dec 2025, already lists ASI06 Memory and Context Poisoning, with mitigations of validating anything written to persistent memory, keeping context ephemeral by default, scoping memory per user and task, and giving operators the ability to inspect and flush stored agent information (source: https://cycode.com/blog/owasp-top-10-agentic-applications/, Jul 2026)

Contradictions:
- Vendors improved memory quality by removing user authorship of it. OpenAI's dreaming and Anthropic's categorised entries both make memory more useful and less user-curated in the same change, while the AEPD requires procedures for exercising data subject rights over the same stores.
- Memory is treated as personal data by regulators and as protected work product by courts within the same quarter, so the same store attracts a disclosure duty toward the data subject and a disclosure shield against opposing parties.
- Deletion is advertised and incomplete: users can delete memory entries and conversations, but deleting a conversation does not delete the memories derived from it, so the visible control does not correspond to the underlying state.

Ledger Candidates:
- A major agent or assistant platform (OpenAI, Anthropic, Microsoft or OpenClaw) ships a user-visible memory-write provenance or confirmation control, documented in official product or developer documentation, showing the originating source of each persistent memory entry and/or requiring explicit confirmation before an agent writes to persistent memory. Resolve by 2027-04. (motivated by: https://thehackernews.com/2026/07/new-memghost-attack-plants-persistent.html, Jul 2026)
- OpenAI or Anthropic documents a deletion-propagation guarantee in official help documentation, stating that deleting a source conversation also deletes memories derived from that conversation. Resolve by 2027-06. (motivated by: https://www.techtimes.com/articles/317840/20260605/chatgpt-memory-dreaming-update-openai-rewrites-personalization-engine-limits-audit-trail.htm, Jun 2026)

Resolve by 2027-05. (motivated by: https://blog.modelcontextprotocol.io/posts/2026-07-28/, Jul 2026)

Resolve by 2027-06. (motivated by: https://nvd.nist.gov/vuln/detail/CVE-2026-59705, Jul 2026)
